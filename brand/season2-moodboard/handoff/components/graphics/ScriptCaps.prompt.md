The ICL signature: condensed caps headline with one script phrase slicing across it at −8°.

```jsx
<ScriptCaps caps="MATCH DAY" script="Match Day" capsSize={196} scriptColor="var(--icl-green)" />
<ScriptCaps caps={"DAYS\nTO GO"} script="Countdown" scriptColor="var(--icl-orchid)" capsColor="var(--text-on-dark)" />
```

- Script must always cross caps — never set script alone on a loud poster.
- Violet script on light grounds; orchid or green on dark.
