# ICL Season 2 moodboard: "Second Innings"

**This is the Season 2 visual direction. Everything for Season 2 is made to this board.**
It replaces the earlier `brand/design-system/` rules (Montserrat, lowercase headlines, purple-led).

- `ICL-Season2-Moodboard.html` – the board. One self-contained file (fonts, logos and images embedded); open it in any browser, offline included.
- `ICL-Season2-Moodboard.png` – full-page export at 1440px wide, for sharing in chats.
- `handoff/` – the original design handoff: `DESIGN_SYSTEM.md` (full rules), `tokens/*.css`, poster components (`components/`), specimen cards (`guidelines/`) and the poster studio (`ui_kits/social/`).
- `src/` – board source. Edit `moodboard.src.html`, then run `python3 src/build.py`.
  - `references/r01–r20.jpg` – third-party reference posters grouped by device in `build.py`. Direction only: never trace, crop or post them.

## The system in one screen
| | |
|---|---|
| Grounds | Floodlight `#F2F1EC` (default), Pitch Night `#0A2A1C` (countdowns, results), Quiet `#07130D` (tributes) |
| Hit colour | Imama Green `#19C571`: numerals, script, highlights |
| Script / tape | Violet `#5B2A92` on light, Orchid `#C86AE8` on dark |
| Flare | `#FF5B24`: circled dates, the final, LIVE. Max 4% of a poster |
| Type | Big Shoulders Display 900 caps · Mrs Saint Delafield script at −8° · Outfit body · JetBrains Mono data |
| Frame | 1080×1350, 72px sides, 64px top, 54px grid, logo top-left, mono meta top-right, crosshair footer |
| Devices | Giant numeral · script × caps · motion ribbons · UI collage · grid/labels/dates · halftone + torn tape · quiet register |
