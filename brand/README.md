# ICL Season 2 brand assets

- `logo/` – Season 2 lockups (SVG + PNG at 1000/3000px wide)
  - `icl-season2-color.svg` – primary, light grounds
  - `icl-season2-reverse.svg` / `-reverse-transparent.svg` – dark grounds
  - `icl-season2-mono-dark.svg`, `icl-season2-mono-white(-transparent).svg` – single ink
  - `icl-master-no-tagline.svg` – original lockup, no season line
  - `png/compare-original-vs-season2.png` – original JPEG next to the new lockup
  - `source/` – original JPEG, trace + build scripts, Montserrat Bold (OFL) used for the tagline
- `design-system/` – tokens, brand book and component previews (mirror of the published design system)

The wordmark was vector-traced from a 1080px JPEG, not the designer's source file.
For large-format print (banners, jerseys), rebuild from the original AI/SVG if one exists.
